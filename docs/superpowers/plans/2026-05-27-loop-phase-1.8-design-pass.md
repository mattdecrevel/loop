# Loop — Phase 1.8 (Formatting Design Pass) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use `- [ ]`.

**Goal:** A refined, standardized house style that looks polished and leverages Block Kit well: one shared skeleton for every message, contextual per-subtype emoji, muted context blocks for metadata + the source footer, field grids and code tables where they help, and **no timestamp** (Slack shows it). Source site shows on every message.

**Decisions (locked):**
- Footer = **source site only**, muted context block, no timestamp.
- One **standardized skeleton** for all types (signup included — no special minimal case).
- **Contextual emoji** chosen per type AND subtype.
- Metadata → **context block** (muted), not inline body bullets.
- Use **field grids** (`section.fields`) for key/value sets, **code tables** for tabular stats.
- Interactivity stays Phase 2 (Previews still shows disabled placeholder pills).

**Tech:** `lib/render/blocks.ts`, `lib/render/index.ts`, `lib/render/samples.ts`, Vitest.

---

## Standardized skeleton (block order)
1. **section** (mrkdwn): `{emoji} *{Title}*{ · subject}` + optional `_breadcrumb_` + optional body + optional `*Steps*` numbered list + optional `*SubHeader*` groups
2. **section.fields** (optional): 2-col key/value grid
3. **section** (optional): monospace code table
4. **context** (optional): muted metadata, items joined by `  ·  `
5. *(Phase 2)* actions
6. **context**: the source site (always; muted)

`raw` stays exempt (pure passthrough).

## Task 1: Composer redesign (no timestamp, context meta, fields)

**Files:** Modify `lib/render/blocks.ts`; update `tests/render.test.ts`

- [ ] **Step 1:** Replace `RichMessageInput`/`richMessage` (keep `section`, `context`, `codeTable`, `RichSubSection`). Remove `time`; footer is source-only. Add `fields`.
```ts
export interface RichField { label: string; value: string }

export interface RichMessageInput {
  emoji: string;
  title: string;
  subject?: string;
  breadcrumb?: string;
  body?: string;
  steps?: string[];
  subSections?: RichSubSection[];
  fields?: RichField[];                 // 2-col grid
  table?: { columns: string[]; rows: (string | number)[][] };
  meta?: (string | null | undefined)[]; // → muted context block
  footerNote?: string;                   // optional helpful note in the footer, e.g. "Anthropic budget: $2.43 of $25.00 this month"
  siteLabel?: string;                    // source footer (preferred)
  projectSlug?: string;                  // fallback
}

export function richMessage(input: RichMessageInput): SlackBlock[] {
  const head: string[] = [];
  head.push(`${input.emoji} *${input.title}*${input.subject ? ` · ${input.subject}` : ''}`);
  if (input.breadcrumb) head.push(`_${input.breadcrumb}_`);
  if (input.body) head.push(input.body);
  if (input.steps?.length) {
    head.push('*Steps*');
    input.steps.forEach((s, i) => head.push(`${i + 1}. ${s}`));
  }
  for (const ss of input.subSections ?? []) { head.push(''); head.push(`*${ss.header}*`); head.push(...ss.lines); }

  const blocks: SlackBlock[] = [section(head.join('\n'))];

  if (input.fields?.length) {
    blocks.push({ type: 'section', fields: input.fields.map((f) => ({ type: 'mrkdwn', text: `*${f.label}*\n${f.value}` })) });
  }
  if (input.table) blocks.push(section(codeTable(input.table.columns, input.table.rows)));

  const meta = (input.meta ?? []).filter((m): m is string => Boolean(m && m.trim()));
  if (meta.length) blocks.push(context(meta.join('  ·  ')));

  const source = input.siteLabel ?? input.projectSlug;
  const footer = [input.footerNote, source].filter((s): s is string => Boolean(s && s.trim())).join('  ·  ');
  if (footer) blocks.push(context(footer));
  return blocks;
}
```
The footer context renders e.g. `Anthropic budget: $2.43 of $25.00 this month  ·  prflio.com` — helpful note first, source site last, no timestamp.

## Task 2: Contextual emoji + standardized renderers

**Files:** Modify `lib/render/index.ts`; update `tests/render.test.ts`

- [ ] **Step 1:** Replace the flat emoji map with a contextual resolver:
```ts
function pickEmoji(ev: ParsedEvent): string {
  const p = ev.payload as Record<string, any>;
  switch (ev.type) {
    case 'error': return '🚨';
    case 'feedback': return ({ bug: '🐛', question: '❓', feature: '💡', general: '💬' } as Record<string,string>)[p.category] ?? '💬';
    case 'subscription': return ({ new: '🎉', upgrade: '⬆️', cancel: '👋', payment_failed: '⚠️', refund: '💸', addon: '➕' } as Record<string,string>)[p.kind] ?? '💳';
    case 'signup': return '👤';
    case 'cron': return p.ok ? '✅' : '⚠️';
    case 'infra': return ev.severity === 'error' ? '🔴' : '📡';
    case 'booking': return '📅';
    case 'contact': return '✉️';
    case 'seo_report': return '🔎';
    case 'generic': return (p.emoji as string) ?? 'ℹ️';
    default: return 'ℹ️';
  }
}
```
(Schema additions in `lib/events/schemas.ts` + `packages/client/src/types.ts`, all OPTIONAL: `generic.emoji?: string` (caller emoji override); `seo_report.footerNote?: string` and `generic.footerNote?: string` (helpful footer line, e.g. budget/spend).)
- [ ] **Step 2:** Rebuild each case to the standardized skeleton via `richMessage`, using `pickEmoji(ev)`, and `{ siteLabel: ctx?.siteLabel, projectSlug: ctx?.projectSlug }` (NO time). Specifics:
  - **signup** → standardized now (drop the minimal one-liner): `title: 'New signup'`, `subject: identity`. Gets the source footer like everything else.
  - **feedback** → `title: { bug:'Bug Report', question:'Question', feature:'Feature Request', general:'General Feedback' }[p.category]`, `subject: name && section ? `${name} on ${section}` : (name ?? section)`, breadcrumb, body, steps, `meta: [email+plan, `\`${page}\``, browser+viewport, screen+locale+tz]`.
  - **booking** → use `fields`: `[{label:'Name',value:p.name},{label:'Email',value:p.email},{label:'When',value:p.start}]`; notes → body.
  - **subscription** → `title: 'Subscription'`, `subject: p.kind`, body `p.email`, `meta: [p.plan, amount]`.
  - **cron** → title `p.name`, body `p.summary`/bullets, table passthrough, `meta: [p.ok ? 'ok' : 'failed']`.
  - **seo_report** → subSections (or CTR summary) + top-queries; pass `footerNote: p.footerNote` (e.g. an AI/Anthropic budget line) into the composer so it renders in the footer before the site.
  - **contact** → body `${name} (${email})\n${message}`, subject `p.source`.
  - **infra** → title `p.host`, body `p.message`, meta `[p.metric]`.
  - **generic** → title/body, fields from `p.fields`, subSections/table passthrough.
  - **error** → title `Error`, body `p.message` + stack code block, meta `[\`route\`, source]`.
