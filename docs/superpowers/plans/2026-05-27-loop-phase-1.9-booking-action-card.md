## Task 2: Calendar link helper

**Files:** Create `lib/render/calendar.ts`; Test `tests/calendar.test.ts`

- [ ] **Step 1:** Failing test: `googleCalendarUrl({ title:'Intro call', startIso:'2026-06-01T16:00:00Z', endIso:'2026-06-01T16:30:00Z' })` contains `calendar.google.com` and `dates=20260601T160000Z/20260601T163000Z` and an encoded title.
- [ ] **Step 2:** Implement:
```ts
function compact(iso: string): string { return new Date(iso).toISOString().replace(/[-:]/g, '').replace(/\.\d{3}/, ''); }
export interface CalInput { title: string; startIso: string; endIso?: string; details?: string; location?: string }
export function googleCalendarUrl(i: CalInput): string {
  const start = compact(i.startIso);
  const end = compact(i.endIso ?? new Date(new Date(i.startIso).getTime() + 30 * 60000).toISOString());
  const p = new URLSearchParams({ action: 'TEMPLATE', text: i.title, dates: `${start}/${end}` });
  if (i.details) p.set('details', i.details);
  if (i.location) p.set('location', i.location);
  return `https://calendar.google.com/calendar/render?${p.toString()}`;
}
```
- [ ] **Step 3:** `pnpm test tests/calendar.test.ts` PASS. Commit: `feat(render): google calendar URL helper`.
